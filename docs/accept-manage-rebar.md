# เกณฑ์ตรวจรับ: จัดการเหล็ก — Select Rebar / Select Host / Delete Rebar / Show-Hide Obscured (0.1.0 — ยังไม่เคยรันใน Revit)

ปุ่มทั้ง 4 อยู่ในแผง PK Revit ต่อยอดแนวคิดจากแผง Manage Rebar ของ PK Tool (อ่านโค้ดอ้างอิงเท่านั้น) ใช้ `lib/revotech/reinforcement.py` + `hostpick.py` เดิม และไฟล์ใหม่ `manage.py` (ส่วนแตะ Revit) / `managecalc.py` (ตรรกะล้วน มี unit test)

## เตรียม
- โปรเจกต์ Revit 2026 มี host หลายชนิด: คาน เสา ฐานราก พื้น ผนัง
- เหล็กหลายที่มา: (ก) เหล็กที่ปุ่ม PK Revit สร้าง (Comments = `PKRevit:...`) (ข) Rebar ที่วางมือ (Comments ว่าง) (ค) Area Reinforcement บนพื้น/ผนัง และ Path Reinforcement (ง) Fabric Sheet
- ติดตั้ง `PKRevit.extension` ใหม่ (รวม `lib/`) แล้ว pyRevit > Reload

## กรณีขอบ / ข้อสงสัยที่ต้องดูตอนรันจริง
- **เฉพาะ Revit จริงเท่านั้นที่ยืนยันได้**: ทุกอย่างข้างบนยังไม่เคยรัน; ตรวจแล้วเฉพาะ syntax (python ast), XAML well-formed และ unit test ตรรกะล้วน (`DeleteRebar.pushbutton/test_manage_calc.py`)
- Revit ลบ RebarInSystem ทีละเส้นไม่ได้ (ตามบันทึกใน `reinforcement.py`) จึงลบทั้งระบบ Area/Path; ระบบที่ Comments ไม่ขึ้นต้น `PKRevit:` จะไม่ถูกลบในโหมดค่าตั้งต้น
- ปุ่ม PK Revit ปัจจุบันยังไม่สร้าง Area/Path จึงโหมดค่าตั้งต้นแทบไม่แตะ Area/Path
- `SetUnobscuredInView` ใช้ได้เฉพาะ view บางชนิด (เช่น 3D/มุมมองที่แสดงเหล็กได้); ถ้า Revit ปฏิเสธ รายการนั้นนับเป็น "ไม่สำเร็จ" และแจ้งในสรุป ไม่ crash
- Select Host รองรับตัวระบบ Area/Path ที่เลือกมาด้วย (ผ่านการหา host แบบสแกนครั้งเดียว) — ต้องตรวจจริง
- หมวด host ที่หาเหล็ก Area/Path ได้จำกัดที่พื้น ผนัง ฐานราก (เหมือน `reinforcement.py`)
- Show/Hide Obscured ทำกับ view ที่ active เท่านั้น
