# Gap analysis: โค้ด v2 เทียบกับคลิป (ร่าง — ยังไม่ commit)

สถานะ: อ่านโค้ดแล้ว `script.py`, `ui.xaml`, `bundle.yaml`, `วิธีติดตั้ง.txt` ครบ ส่วน engine 4 ตัวอ่านส่วนหัว (docstring + CONFIG ~130 บรรทัดแรก) ยังไม่ได้อ่านตรรกะเรขาคณิตด้านล่าง
ยังไม่ได้รันใน Revit (ดูหัวข้อ "ทดสอบ")

## v2 ทำอะไรอยู่แล้ว
- **Roof Master (ตัวควบคุม)** `script.py`: เปิดฟอร์ม WPF ธีมขาว-ดำ (PK) แล้วรัน engine ตามลำดับ Hip → Purlin → Valley → Rafter ใน `TransactionGroup` เดียว (Ctrl+Z ครั้งเดียวย้อนทั้งชุด) ขั้นไหนล้มจะหยุดและเก็บของที่ทำแล้วไว้ เรียก engine ด้วย `execfile` พร้อมส่ง `CONFIG_OVERRIDE`
- **ฟอร์ม** `ui.xaml`: ติ๊ก 4 ขั้น, ช่องระยะ 4 ค่า (ห่างแป 340, ห่างจันทัน 1000, แปล่างสุด 340, แปบนสุด 50 มม.), รายการ ✓/✗ ตรวจ family เหล็กในโปรเจกต์ (ตามคำในชื่อ type: จันทัน, แป, ตะเข้สัน, อกไก่, รางน้ำ), ปุ่ม "สร้างโครงหลังคา"
- **HipRidgeGen**: หาขอบร่วมของผืนหลังคา ≥2 ผืน แยกสัน/ตะเข้ตามความลาด วางคาน คาลิเบรตระดับ ตัด miter ที่ยอด
- **PurlinGen**: วางแปขนานเชิงชาย ระยะสม่ำเสมอ ตัดปลายเฉียงที่ตะเข้ (ใช้ void family `REVOTECH_MiterVoidXXS` สร้าง/โหลดอัตโนมัติ) หมุนหน้าตัดตามลาด จอยกับหลังคา
- **RafterGen**: วางจันทันแบบ mirror layout ข้ามแนวพับ ปลายชนเป็นคู่ที่ตะเข้/สัน ตัดหัวเข้ากับตะเข้สัน/อกไก่
- **ValleyGen**: หาแนวพับเว้า วางรางน้ำ + ตะเข้รางคู่ขนาบ ตัดปลายแปที่ชนราง
- ความสามารถร่วม: ค่าตั้งต้นจูนมือ (เช่น `HIP_TOP_ABOVE_MM -15`, `GUTTER_RISE_MM 110`), ลบของเก่าก่อนสร้างใหม่, ตั้งวัสดุได้ (`MATERIAL_NAME`), ปรับ `Z_JUSTIFY`

โค้ดเขียนสำหรับ **Revit 2026 + IronPython 2.7.12** (มีคอมเมนต์ระบุ) ใช้ `c.Id.Value` ก่อน แล้วค่อย fallback `IntegerValue` ซึ่งสอดคล้องกับ API ของ 2024+

## ความเสี่ยงที่เห็นในโค้ด
- engine สื่อสารผ่าน `execfile` + `CONFIG_OVERRIDE` + ตัวแปร global จึงไม่มี interface ชัดเจน และแต่ละ engine ก๊อป helper ซ้ำ (`ename`, `cat_id`, `mm_to_ft` ฯลฯ ซ้ำ 4 ไฟล์) → ควรแยกเป็น lib กลางก่อนเพิ่มโมดูล
- ไฟล์ engine ใหญ่ (55–76 KB) ทดสอบอัตโนมัติไม่ได้ เพราะผูกกับ Revit API ต้องทดสอบด้วยโมเดลจริง
- ค้นหา type ด้วยคำภาษาไทยในชื่อ (`จันทัน`, `ตะเข้`) เปราะ ถ้าชื่อ family ต่างไปจะล้ม — คลิปใหม่แก้ด้วย dropdown เลือกเอง
- ใช้ `execfile` และ IronPython 2.7: ถ้า pyRevit รุ่นใหม่เลิกรองรับ IronPython 2.7 บน Revit 2026/2027 โค้ดจะต้องย้าย (ยังไม่ได้ตรวจ)

## ทดสอบ
ผู้ใช้อนุญาตให้ควบคุม Revit ที่เปิดอยู่ ผมเห็นหน้าจอ Revit 2026.4 พร้อมแท็บ REVOTECH และโมเดลทดสอบหลังคา 6 หลัง (กากบาท, สี่เหลี่ยมสองแบบ, ปั้นหยา, ตัว L) แต่ยังคลิกใน Revit ไม่ได้: ระบบแจ้งว่า "desktop shell is frontmost" เพราะหน้าต่าง Revit ไม่ขึ้นหน้าสุด ต้องให้ผู้ใช้คลิกที่หน้าต่าง Revit หนึ่งครั้ง หรืออนุมัติสิทธิ์ File Explorer (คลิก taskbar)

### ผลที่ทดสอบจริง (6 พ.ย. 2026, Revit 2026.4, โปรเจกต์ "Revit ครั้งที่ 3 G13")
