# PK Revit เป็น "Super Plugin": ควรทำอะไรได้บ้าง

ข้อมูลที่ยืนยันแล้ว/ยังไม่ยืนยันแยกให้ชัด ที่มา: ค้นเว็บ (เอกสาร Revit API, หน้าสินค้า Graitec PowerPack, บทความ AGACAD) + สิ่งที่ผู้ใช้ทดสอบเอง
**ไม่ได้พบข้อมูลจาก TikTok** (ค้นเว็บทั่วไปไม่เจอ) รายการข้อ 3 จึงเป็นข้อเสนอของผม ไม่ใช่รายการที่คนดังแนะนำ

## 1) เหล็ก: Bar Type, รูปเหล็ก (Shape), ตะขอ, ต่อทาบ
ยืนยันจากเอกสาร Revit API ([RebarHookType](https://rvtdocs.com/2026/Autodesk.Revit.DB.Structure.RebarShape)):
- **Bar Type** (`RebarBarType`) กำหนดขนาด/รัศมีงอ และมีค่าความยาวตะขอ override ได้ ชื่อเช่น DB12/RB9 (ที่เรา dropdown ดึงจากโปรเจกต์แล้ว)
- **Hook Type** (`RebarHookType`) = มุม (0–180°) × ตัวคูณความยาวช่วงตรง (ความยาว = เส้นผ่านศูนย์กลาง × ตัวคูณ) มุมที่ใช้ทั่วไป 90/135/180 ส่วน 45° สร้างเพิ่มเองได้ผ่าน `RebarHookType.Create`
- **Rebar Shape** (`RebarShape`) = รูปทรงเหล็กในโปรเจกต์ (ตรง, L, U, ปลอก ฯลฯ) ชื่อมาจาก template/family ที่โหลด **ชื่อแบบ M_00/M_11 ผมยืนยันไม่ได้** ให้ดึงชื่อจริงจากโปรเจกต์ผู้ใช้ (PK Tool ทำแบบนี้และได้ผลดี)
- **ต่อทาบ (lap splice)**: ยังไม่พบ API ตรงๆ ที่สร้าง "ต่อทาบ" เป็นวัตถุ วิธีที่ใช้ได้จริงคือ คำนวณความยาวทาบ (× d ตามมาตรฐาน) แล้วต่อเส้นเหล็กเอง สลับตำแหน่งต่อ (stagger) ไม่ให้ซ้ำจุดเดียวกัน (โมดูลคานทำเรื่องคานยาวเกิน 10 ม. ไว้แล้ว) ต้องให้ session ค้นเพิ่มว่ามี Rebar Coupler/Lap ใน API ปัจจุบันไหม

**สิ่งที่ผู้ใช้ควรเลือกได้ในฟอร์มเหล็ก:** Bar Type, Shape ของเหล็กหลัก/ปลอก, ตะขอปลายซ้าย/ขวา (ไม่มี/45/90/135/180 + ตัวคูณ d), ระยะต่อทาบ (× d) และตำแหน่งต่อ, ระยะหุ้ม จาก Cover Properties ของ Revit

## 2) แก้ตามผลทดสอบจริง (ทำแล้วใน 0.12.1)
- ขั้นรางน้ำ/ตะเฆ่รางไม่เจอรางในหลังคาปั้นหยา → ข้ามแทนหยุดทั้งชุด
- สรุปผล Roof Master เดิมนับตามชื่อ type จึงได้เลขเท่ากันทุกบรรทัด (เมื่อเลือก type เดียวกันทุกขั้น) → เปลี่ยนเป็นนับจำนวนที่แต่ละขั้นสร้างจริง

## 3) ข้อเสนอฟังก์ชันที่ทำให้เป็น Super Plugin (เรียงตามคุ้มค่า)
อ้างอิง: Graitec PowerPack ([Graitec](https://graitec.com/uk/products/powerpack-for-rebar-design-in-revit/)) ที่ขายจุดเด่นเรื่อง tag อัตโนมัติ, แสดงรูปทรงเหล็ก, schedule, ควบคุม visibility; Dynamo/AGACAD ([AGACAD](https://agacad.com/?p=1897)) ที่ทำ rebar อัตโนมัติ
1. **Tag เหล็กอัตโนมัติ + มิติ** บน view/section ที่เลือก
2. **Section/ชีตอัตโนมัติ**: ตัดหน้าตัดคาน/เสาให้เอง วางลงชีต ใส่ tag และตารางบาร์คัท (ต่อจากโมดูลบาร์คัทที่มี)
3. **ตรวจแบบก่อนส่ง**: ตรวจระยะหุ้ม, ระยะห่างเหล็กต่ำสุด, เหล็กไม่มี host, mark ซ้ำ, เหล็กชนกัน (มี Collision แล้ว)
4. **Mark/หมายเลขเหล็กอัตโนมัติ** ตามกลุ่มและส่งออกตารางไป Excel (มี BBS แล้ว เสริมการเรียงเลขข้ามโมเดล)
5. **คัดลอกรายละเอียดเหล็กข้ามชั้น/ข้ามชิ้น** (Propagate ทำแล้ว เสริมโหมดเลือกชั้น)
6. **นำเข้า/ส่งออกข้อมูลชิ้นงาน** กับ Excel (ขนาดหน้าตัด, Mark, เหล็กที่ใช้) เพื่อใส่เหล็กทีเดียวทั้งโครงการตามตาราง
7. **เครื่องมือทั่วไป**: จัดเรียง/เปลี่ยนชื่อ type เป็นชุด, เติมพารามิเตอร์เป็นชุด, ตรวจสุขภาพโมเดล
8. **หลังคา**: ราง/ตะเฆ่ราง, โหมด type เดียวกันทุกขั้น, ตรวจลำดับ — ต้องทดสอบกับหลังคาหลายแบบ (กากบาท, ตัว L) ก่อน

ทุกข้อต้องทดสอบใน Revit จริงก่อนเชื่อผล ตอนนี้ยังตรวจได้แค่ syntax/unit test/render XAML
