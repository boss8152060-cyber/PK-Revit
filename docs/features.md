## A. Rebar Master (ปุ่มบน ribbon: เหล็กฐานราก / เหล็กเสา / เหล็กคาน / เหล็กพื้น / เหล็กบันได + บาร์คัทของแต่ละชนิด)

- รองรับฐานรากหลายแบบ: F1P 0.70x0.70x0.60 (1 เสาเข็ม), F2 1.50x0.70x0.60 (2 เข็ม), F4 1.50x1.50x0.55 (4 เข็ม), ฐานสามเหลี่ยม 3 เข็ม 0.90x0.90 [เห็น]
- หน้าต่าง: ระยะหุ้ม (เช่น 0.075), เหล็กตามด้านยาว/สั้น (ขนาด DB12/DB16 + จำนวน), รูปแบบตะขอ 3 แบบ (เลือก 1), เหล็กรัดรอบ (RB9, จำนวน/ระยะ), ตัวเลือก "ใส่ให้ฐานรากชื่อเดียวกันทั้งอาคาร", พรีวิว 2D ของการจัดเหล็ก, รายการ "ด่านตรวจก่อนสร้าง" (ขึ้น ✗ ถ้ายังไม่เลือกขนาด) [เห็น]
- ฐานสามเหลี่ยม: เหล็ก 3 ทิศ (0°/60°/120°) กำหนดขนาด/จำนวนแต่ละทิศ [เห็น]
- ผล: popup เช่น "ใส่เหล็กแล้ว 1 ฐาน — ตะแกรง 30 เส้น · รัดรอบ 1 วง" [เห็น]

- รอยต่อเหล็กยืนระหว่างชั้น: "ต่อทาบที่รอยต่อชั้น" หรือ "วิ่งเดียวถึงชั้นบนสุด" [เห็น]
- เหล็กปลอก: RB6/RB9, ปลายงอ 135°, ระยะเรียง (เช่น 0.10/0.15), ระยะหุ้ม (0.02–0.025); ระยะปลอกแยกโซน (ใต้ฐาน/ในฐานราก/ข้อต่อคาน-เสา @100) [เห็นจากข้อความใน popup]

### A3 เหล็กคาน

## B. Roof Master (สร้างโครงหลังคาเหล็ก "คลิกเดียว ~15 วินาที")
- เลือกหลังคา (แผ่นเขียวที่เป็น roof/mass) ก่อน ถ้าไม่เลือกขึ้นข้อความ "กรุณาเลือกหลังคาก่อน" [เห็น]
- ติ๊กขั้นตอนได้ + "ทั้งหมด": ตะเฆ่สัน + อกไก่ (Hip Ridge Gen), แป (Purlin Gen), ตะเฆ่ราง + รางน้ำ (Valley Gen), จันทัน (Rafter Gen), ดั้ง (Dang Gen) — รุ่นใหม่มีขั้น 0 (7 ขั้น) [เห็น; ความหมายขั้น 0 **[ไม่แน่ใจ]**]
- พารามิเตอร์เป็นเมตร: ระยะห่างแป (0.34), ระยะห่างจันทัน (1.0), ระยะแปล่างสุด, ระยะแปบนสุด (0.05) [เห็น]
- เลือก family/type ของโครงสร้างจากโปรเจกต์: แป 2C 50x150x20x2.3, ตะเฆ่สัน 2C 50x100x20x3.2, อกไก่ 2C 50x100x20x3, จันทัน C 125x50x20x3.2, ดั้ง (Rectangular/Square Hollow), รางน้ำ 3117_Roof Gutter [เห็น]
- ผล: popup "โครงหลังคาพร้อมแล้ว (n/n ขั้น)" พร้อมจำนวนต่อชนิด (เช่น แป 103, จันทัน 51, ดั้ง 4) และแจ้ง Ctrl+Z ย้อนได้ครั้งเดียว [เห็น]
- รองรับหลังคาทรงปั้นหยา, ตัว L, หลายหลังคาในโมเดล (2 หลัง), หลังคาเพิงหมาแหงน (shed) [เห็น]; หลังคาทรงซับซ้อนมาก ผู้พูดบอกว่าใช้ได้ "ไม่ว่าจะเป็น..." [ไม่แน่ใจเนื้อหา]
- ปุ่มแยก Gen บน ribbon: Purlin, HipRidge, Valley, Rafter, Dang, RidgeCap, Dang Fam, QTO Tables [เห็น]

## C. Roof Cover (วัสดุมุงและอุปกรณ์หลังคา)
