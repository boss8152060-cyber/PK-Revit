# เกณฑ์ตรวจรับ: Dang Gen ดั้ง (ขั้นที่ 5 ของ Roof Master — ยังไม่เคยรันใน Revit)

ดั้ง = เสาสั้นตั้งแนวดิ่งใต้อกไก่ / จุดรวมตะเข้สัน ลงถึงโครงรับด้านล่าง
(ในคลิป features.md B: เห็นรายการ "ดั้ง" ในฟอร์มและผลสรุป "ดั้ง 4" แต่ **ไม่เห็นการวางจริง** — ตำแหน่ง/ระยะด้านล่างเป็นค่าที่ตั้งสมมติ ดูคำถามท้ายไฟล์)

## เตรียม
- โปรเจกต์ Revit 2026 มีหลังคา และรัน Hip Ridge Gen แล้ว (มี type ชื่อมี `ตะเข้` / `อกไก่`)
- มี Structural Column type อย่างน้อย 1 ตัว (ควรเป็นท่อเหล็กสี่เหลี่ยม/Square Hollow) — ถ้ามี type ชื่อมี `ดั้ง` จะใช้ตัวนั้น ถ้าไม่มี จะ duplicate เป็น `ดั้ง` ให้
- ติดตั้ง `REVOTECH.extension` ใหม่ (ต้องมี `engines/DangGen.pushbutton/dang_calc.py` มาด้วย) แล้ว pyRevit > Reload
- (ถ้าอยากให้ดั้งลงถึงคาน/พื้น) มีคาน Structural Framing หรือพื้นใต้อกไก่ และมี 3D view ที่เห็นของเหล่านั้น

## กรณีขอบ
- หลังคาจั่ว (อกไก่เส้นเดียว): ได้ดั้งที่ปลายอกไก่ 2 จุด (RIDGE_ENDS_ALWAYS)
- หลังคาเพิงหมาแหงน (ไม่มีอกไก่/ตะเข้): ไม่มีดั้ง (alert)
- ตะเข้ที่ชนกันเกิน 2 เส้นที่ยอด (พีระมิด): ดั้งเดียวที่จุดนั้น
- ไม่มี 3D view: ใช้ความยาวที่กรอกทุกตัว (แจ้ง ⚠)
- ถ้ามีเฉพาะ Framing type ชื่อ `ดั้ง`: ลองวางคานแนวดิ่ง — Revit อาจปฏิเสธ (นับเป็น "สร้างไม่สำเร็จ") ควรใช้ Column type

## ที่ยังไม่รองรับ / ข้อจำกัด
- duplicate จาก type จันทัน ไม่ได้ (จันทันเป็น Framing, ดั้งต้องเป็น Column) → duplicate จาก Column type ที่มีแทน ขนาดหน้าตัดต้องตั้งเอง
- ยอดดั้งคำนวณจาก "เส้นอ้างอิงคาน − ความลึกคาน (100 มม.)" ไม่ได้อ่านความลึกจริงของ type
- ไม่ได้ join ดั้งกับคาน/หลังคา

## คำถามที่ต้องให้ผู้ใช้ยืนยัน (ค่าตั้งต้นที่ตั้งไว้)
1. ดั้งอยู่ตรงไหนจริงๆ ในคลิป — ใต้ปลายอกไก่ + จุดรวมตะเข้ (ที่ตั้งไว้) หรืออยู่กลางแนวอกไก่ด้วย? (มีตัวเลือก `RIDGE_MAX_SPAN_MM` ตั้งตั้งต้น 0 = ปิด)
2. ในคลิปตัวอย่างสรุป "ดั้ง 4" — หลังคาแบบไหน ตำแหน่งตรงกับ 2 จุดปั้นหยาหรือไม่ (ปั้นหยาปกติจะได้ 2)
3. ดั้งลงถึงอะไร: คานโครงรับ / พื้น / Level ที่กำหนด? ตอนนี้ยิงรังสีลงหาคาน+พื้น ใกล้สุดใต้จุด ลึกไม่เกิน 4000 มม. ไม่งั้นใช้ความสูงสำรอง 1000 มม.
4. ความสูงสำรอง 1000 มม. และขนาดหน้าตัดดั้ง (ในคลิป: Rectangular/Square Hollow ขนาด?) 
5. ความลึกคานอกไก่ที่ใช้ตั้งยอดดั้ง 100 มม. ถูกไหม (2C 50x100)
6. ดั้งในคลิปเป็น Column หรือ Framing? (ตอนนี้ใช้ Column)
7. ปลายอกไก่ทุกจุดต้องมีดั้งไหม แม้ไม่มีตะเข้มาชน (ตอนนี้ใช่)
