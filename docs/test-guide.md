# คู่มือทดสอบสั้นๆ (ทำใน Revit 2026)

เป้าหมาย: ทดสอบทุกปุ่มบนแท็บ PK Revit ให้เร็วที่สุด แล้วส่งผลกลับมาให้ผม (ภาพหน้าจอกล่องข้อความ + ไฟล์ log)

## เตรียม
1. ใช้ **สำเนา** ของโปรเจกต์ ไม่ใช้ไฟล์จริง
2. pyRevit > **Reload** (หรือรีสตาร์ท Revit) เพื่อโหลดชุดล่าสุด
3. แท็บ PK Revit ต้องมีปุ่ม: บาร์คัท, Rebar คาน/เสา/ฐานราก/พื้น/บันได, Roof Cover, Roof Master, QTO Tables, License
   - ปุ่มไหนหาย: เปิด pyRevit > Show output / log แล้วส่งข้อความ error มา
4. ต้องมี Rebar Bar Type ในโปรเจกต์ (Structure > Reinforcement Settings) ไม่งั้นฟอร์มเหล็กจะไม่ยอมสร้าง

## ลำดับทดสอบ (ใช้เวลาประมาณ 30 นาที)
| # | ปุ่ม | ทำ | ส่งกลับ |
|---|---|---|---|
| 1 | Roof Master | เลือกหลังคา 1 หลัง → กด → เลือก type จากแต่ละ dropdown → สร้าง | ภาพ popup สรุป, 3D ที่ได้, ข้อความ error ถ้ามี |
| 2 | Roof Cover | เลือกหลังคาเดิม → เลือกวัสดุ → สร้าง | ภาพผลใน 3D + popup |
| 3 | Rebar เสา | เลือกเสา 1 ต้น 4 เส้น + ปลอก → สร้าง → Ctrl+Z | ภาพ 3D เหล็ก, ผล Ctrl+Z |
| 4 | Rebar คาน | เลือกคาน 1 ตัว → สร้าง | ภาพ 3D + popup |
| 5 | Rebar ฐานราก | เลือกฐานราก → สร้าง | ภาพ 3D + popup |
| 6 | Rebar พื้น | เลือกพื้น → โหมดเหล็กเส้น → สร้าง | ภาพ 3D + popup |
| 7 | Rebar บันได | เลือกบันได → สร้าง | ภาพ 3D + popup |
| 8 | บาร์คัท | หลังข้อ 3–7 กดปุ่มบาร์คัท → ทั้งโมเดล | popup + ไฟล์ที่ส่งออก + ชีต |
| 9 | QTO Tables | กดหลังข้อ 1–2 | ตารางที่ขึ้น |
| 10 | License | เปิดดู ลองเปลี่ยนภาษา | ภาพฟอร์ม |
| 11 | Select Rebar / Select Host | หลังข้อ 3 เลือกเสา → Select Rebar → เลือกเหล็ก → Select Host | จำนวนที่เลือกได้ |
| 12 | Delete Rebar | เลือกเสา → ดูกล่องยืนยัน → ลบ → Ctrl+Z | จำนวนในกล่องยืนยัน, ผล Ctrl+Z |
| 13 | Show/Hide Obscured | เปิดฟอร์ม เลือกเสา + Rebar → Show แล้ว Hide | เหล็กเปลี่ยนใน view หรือไม่ |
| 14 | Rebar Collision | ใช้กับคาน/เสาที่ชนกัน | รายงาน + ลองคลิกแถว |
| 15 | Color by Parameter | เลือกพารามิเตอร์ → Scan → Apply → Reset | ภาพสี |
| 16 | Propagate Rebar | เสาต้นแรกที่ใส่เหล็กแล้ว → เลือกต้นอื่น | เหล็กเกิดตามความสูงของแต่ละต้น |
| 17 | Preset | ในฟอร์มเหล็ก บันทึก preset → ปิด → เปิดใหม่ → โหลด | ค่ากลับมาครบ |

ไฟล์ log อยู่ที่ `%LOCALAPPDATA%\PKRevit\` (เช่น `Rebar_column.txt`) เปิดแล้วส่งเนื้อหามาได้เลย
เกณฑ์ตรวจรับละเอียดของแต่ละโมดูลอยู่ใน `docs/accept-*.md`

## ถ้าเจอปัญหา
- ฟอร์มไม่ขึ้น/ปุ่มกดแล้วเงียบ: เปิด pyRevit output window ดู traceback
- เหล็กไม่เกิดบางชิ้น: ดูบรรทัด "ข้าม" ใน log (มักเป็นหน้าตัดเล็กเกินระยะหุ้ม หรือรูปทรงไม่ใช่สี่เหลี่ยม)
- ผลเรขาคณิตผิด (เหล็กหลุดตำแหน่ง): ส่งภาพ 3D + ขนาดของชิ้นงานจริงมาให้ ผมจะแก้ตามนั้น
