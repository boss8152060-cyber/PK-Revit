# คู่มือทดสอบสั้นๆ (ทำใน Revit 2026)

เป้าหมาย: ทดสอบทุกปุ่มบนแท็บ PK Revit ให้เร็วที่สุด แล้วส่งผลกลับมาให้ผม (ภาพหน้าจอกล่องข้อความ + ไฟล์ log)

## เตรียม
1. ใช้ **สำเนา** ของโปรเจกต์ ไม่ใช้ไฟล์จริง
2. pyRevit > **Reload** (หรือรีสตาร์ท Revit) เพื่อโหลดชุดล่าสุด
3. แท็บ PK Revit ต้องมี 4 panel (รายละเอียดใน `docs/ribbon-layout.md`):
   - **เหล็ก**: ปุ่ม Rebar + pulldown จัดการเหล็ก (Select Rebar, Select Host, Delete Rebar, Show/Hide Obscured, Rebar Collision, Color by Parameter, Propagate Rebar)
   - **หลังคา**: ปุ่ม Roof (เลือก โครงหลังคา / วัสดุมุง)
   - **ผลลัพธ์**: pulldown บาร์คัท & QTO (บาร์คัท, QTO Tables)
   - **ตั้งค่า**: License
   - ปุ่มไหนหาย: เปิด pyRevit > Show output / log แล้วส่งข้อความ error มา
   - ชื่อ panel เป็นภาษาไทย ถ้า panel/ปุ่มไม่ขึ้นเลยหลัง Reload ให้ส่ง log มา (เสี่ยงเรื่องชื่อโฟลเดอร์ภาษาไทยกับ pyRevit)
4. ต้องมี Rebar Bar Type ในโปรเจกต์ (Structure > Reinforcement Settings) ไม่งั้นฟอร์มเหล็กจะไม่ยอมสร้าง

## ลำดับทดสอบ (ใช้เวลาประมาณ 35 นาที)
| # | ปุ่ม | ทำ | ส่งกลับ |
|---|---|---|---|
| 1 | Roof → โครงหลังคา | เลือกหลังคา 1 หลัง → กด Roof → เลือก "โครงหลังคา" → เลือก type จากแต่ละ dropdown → สร้าง | ภาพ popup สรุป, 3D ที่ได้, ข้อความ error ถ้ามี (เช็คด้วยว่าฟอร์มเปิดได้ = หา ui.xaml เจอ และ engine ครบทั้ง 5 ขั้น) |
| 2 | Roof → วัสดุมุง | เลือกหลังคาเดิม → กด Roof → "วัสดุมุง" → เลือกวัสดุ → สร้าง | ภาพผลใน 3D + popup |
| 3 | Rebar (เสา) | เลือกเสา 1 ต้น แล้วกด Rebar → ต้องเปิดฟอร์มเสาทันที ไม่ผ่านหน้าต่างเลือก → 4 เส้น + ปลอก → สร้าง → Ctrl+Z | ภาพ 3D เหล็ก, ผล Ctrl+Z |
| 4 | Rebar (คาน) | เลือกคาน 1 ตัว → Rebar → สร้าง | ภาพ 3D + popup |
| 5 | Rebar (ฐานราก) | เลือกฐานราก → Rebar → สร้าง | ภาพ 3D + popup (ฟอร์มนี้ import footing_calc ข้างไฟล์ — ถ้า error ModuleNotFound ส่งมา) |
| 6 | Rebar (พื้น) | เลือกพื้น → Rebar → โหมดเหล็กเส้น → สร้าง | ภาพ 3D + popup |
| 7 | Rebar (บันได) | เลือกบันได → Rebar → สร้าง | ภาพ 3D + popup |
| 7a | Rebar ไม่ได้เลือกอะไร | ไม่เลือกอะไรเลย กด Rebar | ต้องขึ้นหน้าต่าง 5 ปุ่ม (เสา/คาน/ฐานราก/พื้น/บันได) → กดเสา → ต้องให้คลิกเลือกเสา → เปิดฟอร์มเสา |
| 7b | Rebar เลือกปน | เลือกเสา 2 ต้น + พื้น 1 แผ่นพร้อมกัน กด Rebar | ต้องถามว่าทำทีละชนิด (เสา → พื้น) → ฟอร์มเสา → ถามต่อ → ฟอร์มพื้น (ตรวจว่าแต่ละฟอร์มนับเฉพาะชนิดของตัวเอง) |
| 7c | Rebar เลือกสิ่งที่ไม่รองรับ | เลือกกำแพงอย่างเดียว กด Rebar | ต้องขึ้นหน้าต่างเลือกชนิด (ถือว่าไม่มีชนิดที่รองรับ) |
| 8 | บาร์คัท | หลังข้อ 3–7 pulldown ผลลัพธ์ → บาร์คัท → ทั้งโมเดล | popup + ไฟล์ที่ส่งออก + ชีต |
| 9 | QTO Tables | pulldown ผลลัพธ์ → QTO Tables หลังข้อ 1–2 | ตารางที่ขึ้น |
| 10 | License | panel ตั้งค่า เปิดดู ลองเปลี่ยนภาษา | ภาพฟอร์ม |
| 11 | Select Rebar / Select Host | pulldown จัดการเหล็ก หลังข้อ 3 เลือกเสา → Select Rebar → เลือกเหล็ก → Select Host | จำนวนที่เลือกได้ |
| 12 | Delete Rebar | เลือกเสา → ดูกล่องยืนยัน → ลบ → Ctrl+Z | จำนวนในกล่องยืนยัน, ผล Ctrl+Z |
| 13 | Show/Hide Obscured | เปิดฟอร์ม เลือกเสา + Rebar → Show แล้ว Hide | เหล็กเปลี่ยนใน view หรือไม่ |
| 14 | Rebar Collision | ใช้กับคาน/เสาที่ชนกัน | รายงาน + ลองคลิกแถว |
| 15 | Color by Parameter | เลือกพารามิเตอร์ → Scan → Apply → Reset | ภาพสี |
| 16 | Propagate Rebar | เสาต้นแรกที่ใส่เหล็กแล้ว → เลือกต้นอื่น (ต้องหาโมดูลใน Rebar/modules เจอ) | เหล็กเกิดตามความสูงของแต่ละต้น |
| 17 | Preset | ในฟอร์มเหล็ก (เปิดผ่านปุ่ม Rebar) บันทึก preset → ปิด → เปิดใหม่ → โหลด | ค่ากลับมาครบ (preset ยังเก็บแยกตามชนิดเหมือนเดิม) |

ไฟล์ log อยู่ที่ `%LOCALAPPDATA%\PKRevit\` (เช่น `Rebar_column.txt`) เปิดแล้วส่งเนื้อหามาได้เลย
เกณฑ์ตรวจรับละเอียดของแต่ละโมดูลอยู่ใน `docs/accept-*.md`

## ถ้าเจอปัญหา
- ฟอร์มไม่ขึ้น/ปุ่มกดแล้วเงียบ: เปิด pyRevit output window ดู traceback
- เหล็กไม่เกิดบางชิ้น: ดูบรรทัด "ข้าม" ใน log (มักเป็นหน้าตัดเล็กเกินระยะหุ้ม หรือรูปทรงไม่ใช่สี่เหลี่ยม)
- ผลเรขาคณิตผิด (เหล็กหลุดตำแหน่ง): ส่งภาพ 3D + ขนาดของชิ้นงานจริงมาให้ ผมจะแก้ตามนั้น
