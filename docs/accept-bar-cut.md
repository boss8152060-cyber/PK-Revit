# เกณฑ์ตรวจรับ: บาร์คัท (0.1.0 — ยังไม่เคยรันใน Revit)

ฟีเจอร์อ้างอิง: `docs/features.md` section A6 · โค้ด: `BarCut.pushbutton/` (คำนวณใน `bar_cut_calc.py`, ส่งออกใน `bar_cut_export.py`, ทดสอบนอก Revit แล้ว 14 เคส `test_bar_cut_calc.py`)

## ทำอะไร
1. เก็บ Rebar ที่ Comments ขึ้นต้น `PKRevit:` (column / beam / footing / slab / stair) ตามขอบเขต: ทั้งโมเดล · เฉพาะที่เลือก (เลือกตัวเหล็กหรือ element โฮสต์ก็ได้) · ติ๊กตามชนิด
2. อ่านรูปเหล็กจาก `Rebar.GetCenterlineCurves` (ตัดรัศมีโค้ง) → จัดกลุ่มเป็น **เลขบาร์** = (ขนาด, รูปทรง, ความยาวตัดปัด 5 มม.) รูปทรงเดียวกันที่เริ่มคนละปลายนับเป็นเลขเดียว
3. ตารางตัดเหล็ก: เลข, ขนาด, รูปตัด+มิติ, จำนวนท่อน, ความยาวตัด, ความยาวรวม, น้ำหนัก
4. แผนตัดท่อนสต็อก 10 หรือ 12 ม. + เผื่อรอยตัด (มม./การตัด) แบบ first-fit-decreasing แยกตามขนาด → จำนวนท่อนสั่ง, แบบตัด A/B/C, เศษ, % เศษตามความยาวและตามน้ำหนัก
5. ส่งออก `.xlsx` (เขียนเองด้วย zipfile+XML 3 ชีต: ตารางตัดเหล็ก / แผนตัด / สรุป) หรือ `.csv` UTF-8 BOM (ทางเลือกถ้า xlsx เปิดไม่ได้ในเครื่องใด)
6. สร้างชีต Revit (ถ้ามี Title Block): ชีตต่อชนิดงาน + ชีตสรุปรวม พร้อม Schedule ของ Rebar
7. Transaction เดียว; popup สรุป เช่น `32 แนว · 207 เลข · 7,407 กก. · 10 ม. 615 ท่อน`; log ที่ `%LOCALAPPDATA%\PKRevit\BarCut.txt`

## ข้อจำกัด / ส่วนที่ยังทำไม่ได้ (ระบุตรงๆ)
- **ไม่เคยทดสอบใน Revit 2026** — API ที่เสี่ยงที่สุด: การสร้าง Schedule (ชื่อ BuiltInParameter บางตัวอาจต่างรุ่น), ScheduleSheetInstance, ตำแหน่งวางบนชีต, `GetCenterlineCurves` signature
- **ตารางบนชีตเป็น Schedule ของ Rebar** ซึ่งแสดงได้เฉพาะ Mark / ขนาด / ความยาว / จำนวน / ความยาวรวม; **ไม่มีคอลัมน์รูปตัด+มิติ, ความยาวตัดตามมาตรฐาน, น้ำหนัก** (ไม่มีพารามิเตอร์มาตรฐานรองรับ) — ข้อมูลเต็มอยู่ใน Excel/CSV; บนชีตมีเพียง text note สรุปจำนวนเส้น/กก. ต่อชนิด และสรุปแผนตัดต่อขนาดในชีตรวม
- **ยังไม่ทำ**: รูป 3D เหล็กทั้งชุดบนชีต, รูปทรงเหล็กแยกกลุ่ม (shape drawing), Viewport ใดๆ, แยกชีตตามแนวคาน (`BC-X.n`/`BC-Y.n` ต้องรู้ grid/แนวคาน) — ตอนนี้ใช้ชีตเดียวต่อชนิดงาน เลขเรียง `XX-01…` และ `BC-00` เป็นชีตสรุปรวมทุกชนิด (ไม่ใช่เฉพาะคาน)
- ชีตวาง Schedule ที่มุมซ้ายบน และ text note ที่ซ้ายล่างโดยคำนวณจาก `ViewSheet.Outline` — อาจทับกรอบ/ตาราง Title Block ต้องดูจริงแล้วปรับ
- ปุ่มเสริมบน ribbon (ตรวจ/ส่อง/สี) ไม่แน่ใจหน้าที่ ยังไม่ทำ
- ความยาวตัด = ความยาวเส้นศูนย์กลางแบบมุมแหลม (ไม่หักรัศมีโค้ง/ไม่ใช้สูตรตัดเหล็กงอแบบมาตรฐานโรงงาน) อาจต่างจากตัวเลขสั่งตัดจริงเล็กน้อย
- เหล็กชุดที่ความยาวแต่ละเส้นไม่เท่ากัน (varying length) ถือทุกเส้นยาวเท่าเส้นแรก; แผนตัดไม่ต่อทาบ — ชิ้นที่ยาวกว่าสต็อกถูกแยกรายงาน "ต้องต่อทาบ" ไม่รวมในจำนวนท่อน
- "จำนวนแนว" ใน popup = จำนวน element โฮสต์ที่มีเหล็ก (คาน/เสา/ฐานราก ฯลฯ) ไม่ใช่ "แนว" แบบในคลิปแน่นอน (**ไม่แน่ใจ** นิยามในคลิป)
- ตัวเลือกเผื่อรอยตัด: นับ 1 รอยต่อการตัดระหว่างชิ้นในท่อนเดียวกัน (n ชิ้น = n−1 รอย; เศษปลายไม่หัก) — ตีความเอง ยืนยันกับผู้ใช้

## ค่า/ข้อสมมติที่รอยืนยัน
- น้ำหนักหน่วย kg/m ตั้งต้น (แก้ได้ที่ `UNIT_WEIGHT` ใน `bar_cut_calc.py`): RB6 0.222 · RB9 0.499 · DB10 0.617 · DB12 0.888 · DB16 1.578 · DB20 2.466 · DB25 3.853 · DB28 4.834 · DB32 6.313 — **ต้องให้วิศวกรยืนยันกับตารางมาตรฐาน (มอก.) ก่อนใช้สั่งซื้อ**; ขนาดอื่นใช้สูตร d²/162.2
- รอยตัดตั้งต้น 3 มม.; ท่อนสต็อก 10/12 ม.
- คำนำหน้าเลขชีต: เสา `CL` (ตีความเอง), คาน `BC`, ฐานราก `FT`, พื้น `SL`, บันได `ST`
- ชื่อรูป bar type ใช้เลขในชื่อ (`DB12` → 12) เหมือนโมดูลเหล็กอื่น
