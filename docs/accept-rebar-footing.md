# เกณฑ์ตรวจรับ: Rebar ฐานราก (0.1.0 — ยังไม่เคยรันใน Revit)

ฟีเจอร์อ้างอิง: `docs/features.md` section A1 · โค้ด: `RebarFooting.pushbutton/` (คำนวณใน `footing_calc.py` ทดสอบนอก Revit แล้ว 16 เคส)

## เตรียม
- โปรเจกต์ Revit 2026 มี Structural Foundation (isolated footing) ผังเป็นสี่เหลี่ยมมุมฉาก (F1P 0.70x0.70x0.60, F2 1.50x0.70x0.60, F4 1.50x1.50x0.55) และฐานสามเหลี่ยม 3 เสาเข็ม (0.90x0.90)
- มี Rebar Bar Type ชื่อ `DB12/DB16/...` และ `RB9` (ที่จะใช้)
- ติดตั้ง `REVOTECH.extension` ใหม่ (ต้องมี `lib/`) แล้ว pyRevit > Reload

## กรณีขอบ
- ผังฐานไม่ใช่สี่เหลี่ยมมุมฉากหรือสามเหลี่ยม (หลายเหลี่ยม/มีมุมเอียง) → ข้ามพร้อมบันทึกใน log
- ฐานเล็ก/บางเกินระยะหุ้มบวกขนาดเหล็ก → ข้ามหรือขางอสั้นลง (จำกัดไม่เลยระยะหุ้มบน)
- ไม่มี Bar Type ที่เลือก → ด่านตรวจขึ้น ✗ ชื่อขนาดนั้น
- เหล็กรัดรอบเกินความสูงฐาน → ตัดวงที่เกินทิ้ง
- ฐานรากแบบ Slab (Foundation Slab) ที่ผังไม่ใช่ 3/4 มุม → ข้าม
- error กลางทาง → ย้อนกลับทั้งหมด ไม่ทิ้งเหล็กค้าง

## ขอบเขตที่ยังไม่ทำ (จาก A1)
- พรีวิว 2D ของการจัดเหล็กในหน้าต่าง (เห็นในคลิป แต่ยังไม่ได้ทำ)
- เหล็กชั้นบน, เหล็กเสาเข็ม/เสาตอม่อ, ฐานแบบ 5 เข็มขึ้นไป

## ค่า/ข้อสมมติที่รอวิศวกรยืนยัน
- ระยะหุ้มตั้งต้น 75 มม. (คลิปแสดง 0.075) — ตรงกับฐานรากสัมผัสดินตามมาตรฐานทั่วไปหรือไม่
- ปลายงอ 90° = 12d (ค่าจาก `revotech.rebar.HOOK90_EXT_D`) และจำกัดไม่ให้เกินใต้ระยะหุ้มบน
- **รูปแบบตะขอ 3 แบบ**: คลิปไม่ระบุชื่อชัด ใช้การตีความ = (1) งอขึ้น 90° ยาว 12d (2) งอขึ้น 90° ยาวถึงใต้ระยะหุ้มบน (3) เหล็กตรงไม่งอ — ต้องยืนยันจากคลิป/ทีม
- "ตามด้านยาว/ด้านสั้น": ตีความว่าเหล็กวิ่งขนานด้านนั้น กระจายตลอดความกว้างฐาน; ชั้นล่างสุดคือด้านยาว (ลำดับชั้นตามหลักปฏิบัติ ยังไม่ยืนยัน)
- ฐานสามเหลี่ยม: ทิศ 0° อ้างแกน X local ของฐาน, ชั้นล่าง→บนคือ 0°,60°,120°, เหล็กกระจายเว้นขอบ (ไม่วางชิดขอบ) เพื่อไม่ให้ความยาวเหล็กเหลือศูนย์ที่มุม
- เหล็กรัดรอบ: ตีความเป็นวงปิดแนวราบรอบผังฐาน วางเหนือตะแกรง เรียงขึ้นด้านบนตามระยะ; ไม่มีตะขอ/ทาบปลาย — ต้องยืนยันรูปแบบจริงและค่าตั้งต้น (RB9 จำนวน/ระยะ)
- ชั้นเหล็กไม่ได้ตรวจการชนกันของตะขอกับเหล็กเสาตอม่อ
