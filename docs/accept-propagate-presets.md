# เกณฑ์ตรวจรับ: จำค่าต่อ element + Propagate Rebar + Preset (ยังไม่เคยรันใน Revit)

> เขียนและตรวจได้เฉพาะ syntax, unit test ของตรรกะล้วน (`test_propagate_presets.py`) และ render XAML ด้วย WPF
> **ยังไม่ได้ทดสอบใน Revit 2026 เลย** — ส่วน ExtensibleStorage / PostCommand / ฟอร์ม Preset ต้องให้ผู้ใช้รันจริง

## ส่วนที่เพิ่ม
- `lib/revotech/hostconfig.py` — จำค่าฟอร์มที่ host (schema `PKRevitHostConfig`, GUID ของ PK Revit เอง ไม่ชนของ PK Tool)
- โมดูลเหล็ก 5 ตัว (เสา/คาน/ฐานราก/พื้น/บันได): บันทึกค่าลง host ทุกตัวที่สร้างสำเร็จ + รองรับ `CONFIG_OVERRIDE = {"values": {...}, "hosts": [ElementId]}` (ไม่เปิดฟอร์ม) — ไม่มี override พฤติกรรมเดิม
- ปุ่ม **Propagate Rebar** (`PropagateRebar.pushbutton`)
- แถบ **Preset** ในฟอร์ม `revotech.ui.RevoWindow` ทุกฟอร์ม (ยกเว้นฟอร์มลิขสิทธิ์ที่มีรหัสในช่องกรอก): `presetlogic.py` (ตรรกะล้วน), `presetstore.py` (Local ไฟล์ / Project ExtensibleStorage)

## เตรียม
- โปรเจกต์ Revit 2026 มีเสา/คาน/ฐานราก/พื้น/บันได ที่ขนาดต่างกันหลายตัว และมี Bar Type ที่ใช้
- ติดตั้ง `PKRevit.extension` ใหม่ทั้งโฟลเดอร์ (ต้องมี `lib/`) แล้ว pyRevit > Reload

## B) Propagate Rebar
| # | ทำ | คาดหวัง |
|---|---|---|
| B1 | ไม่เลือกอะไร กดปุ่ม | ถามเลือก host ต้นทาง; ยกเลิกแล้วจบเงียบๆ |
| B2 | เลือกเสาต้นทางที่ใส่ด้วย PK Revit แล้ว กดปุ่ม → เลือกเสาปลายทาง 3 ต้น (ขนาด/ความสูงต่างกัน) แล้ว Finish | ปลายทางได้เหล็กด้วยค่าเดียวกับต้นทาง **คำนวณใหม่ตามขนาดของแต่ละต้น** (ปลอกกระจายตามความสูงของตัวเอง) ไม่ใช่คัดลอกตำแหน่งตรงๆ; มี popup สรุปของโมดูลเสา; log ใน `%LOCALAPPDATA%\PKRevit\Rebar_column.txt` |
| B3 | Ctrl+Z ครั้งเดียว | เหล็กที่ propagate หายทั้งชุด |
| B4 | Propagate ซ้ำไปปลายทางเดิม | เหล็ก PK Revit เดิมของปลายทางถูกแทนที่ ไม่ซ้อนทับ |
| B5 | เลือกต้นทางหลายตัว | แจ้งให้เลือกครั้งละ 1 ตัว แล้วจบ |
| B6 | ต้นทางเป็นเสา ปลายทางเลือกได้เฉพาะเสา (คาน/พื้นคลิกไม่ได้) | ตัวกรองเลือกชนิดเดียวกันเท่านั้น |
| B7 | ทำ B2 กับ คาน, ฐานราก, พื้น, บันได | ได้ผลในแบบเดียวกัน (บันไดไม่สร้าง 3D view สีซ้ำ) |
| B8 | ต้นทางที่ไม่เคยใส่ด้วย PK Revit แต่มีเหล็กเอง | เลือกเหล็กของต้นทางไว้ให้ แล้วสั่ง Propagate Rebar ของ Revit (`ID_PROPAGATE_REBAR`); Revit ให้เลือกปลายทางต่อเอง |
| B9 | ต้นทางไม่มีเหล็กเลย | แจ้ง "ไม่มีเหล็กให้ propagate" |
| B10 | ถ้าโพสต์คำสั่งไม่ได้ (ไม่พบ command id / PostCommand error) | แจ้งว่าเลือกเหล็กให้แล้ว ให้กด Propagate Rebar ที่แท็บ Rebar เอง |
| B11 | ค่าที่จำไว้ใช้ Bar Type ที่โปรเจกต์นี้ไม่มี (เช่น เปิดไฟล์อื่น) | แจ้งชื่อ Bar Type ที่ขาด แล้วจบ ไม่สร้างอะไรค้าง |

## กรณีขอบ / ข้อจำกัดที่รู้
- Preset เก็บเฉพาะ control ที่มี `x:Name` (TextBox ที่แก้ได้, ComboBox, CheckBox, RadioButton); ข้อความ/ผลตรวจ (TextBlock) ไม่เก็บ; ComboBox ที่ยังไม่ได้เลือกไม่เก็บ
- โหลด preset รันการคืนค่า 2 รอบ เพราะ dropdown บางตัวอาจเปลี่ยนรายการของตัวอื่น
- ค่า tuple ในค่าที่จำไว้ (เช่น จำนวน+ขนาดเหล็กของคาน) กลายเป็น list หลังบันทึก JSON — โมดูลใช้แบบ unpack/index จึงไม่กระทบ (ตรวจจากโค้ดเท่านั้น)
- Propagate กำหนด `replace=True`, `same=False` เสมอ และปิดสร้าง 3D view ของบันได — ค่าที่ใช้นี้จะถูกจำไว้ที่ปลายทางด้วย
- โหมดบันไดแบบ override ข้ามด่านตรวจของฟอร์ม (gate) ถ้าปลายทางกว้างต่างมาก ผลอาจไม่เหมาะ — ตรวจใน log
- บันไดต้องเลือกตัวบันไดเอง (ไม่รองรับเลือก Run/Landing เป็นต้นทาง/ปลายทางของ Propagate)
- schema GUID ของ PK Revit: host `225EDFDD-7030-4A87-8305-B9BF06962BBE`, project preset `141E55A9-4A16-4675-9305-921FF3CC74F8` — ห้ามเปลี่ยนหลังเริ่มใช้งานจริง
- IronPython: การเรียก `Entity.Set[str]` / `Get[str]` และ `AddSimpleField(..., clr.GetClrType(str))` ยังไม่เคยรันจริง ถ้า error ให้ส่งข้อความกลับมา (การจำค่าล้มจะถูกกลืนเงียบ ไม่ทำให้การสร้างเหล็กล้ม แต่ Propagate จะหาค่าไม่เจอ)
