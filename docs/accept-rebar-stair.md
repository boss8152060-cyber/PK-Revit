# เกณฑ์ตรวจรับ: Rebar บันได (0.1.0 — ยังไม่เคยรันใน Revit)

อ้างอิงฟีเจอร์ A5 ใน `docs/features.md` · โค้ด: `RebarStair.pushbutton/` (คำนวณใน `stair_calc.py`, unit test 15 ข้อผ่านนอก Revit)

## เตรียม
- โปรเจกต์ Revit 2026 มีบันไดหล่อในที่แบบ Stairs by Component (Run + Landing) 1–2 ช่วง ช่วงเป็นแนวตรง ชานสี่เหลี่ยม
- มี Rebar Bar Type ชื่อ `RB9` (และ `RB6/DB10/...` ที่จะใช้)
- ติดตั้ง `PKRevit.extension` ใหม่ (ต้องมีโฟลเดอร์ `lib/`) แล้ว pyRevit > Reload

## กรณีขอบ
- ช่วงโค้ง/winder/หักมุม, ชานไม่ใช่สี่เหลี่ยม → ข้าม พร้อมเหตุผลใน log (ชานข้ามได้โดยช่วงยังใส่)
- บันไดมี > 2 ช่วง → ข้ามทั้งตัว
- ช่วงแคบกว่าระยะหุ้ม → ด่านตรวจ ✗
- ถ้า Revit ไม่รับ Run เป็น host ของ Rebar โค้ดลองใช้ตัวบันไดเป็น host แทน; ถ้ายังไม่ได้ → นับเป็น "สร้างไม่สำเร็จ" ใน popup/log (ไม่มีชิ้นค้างเพราะ Transaction เดียว)

## สิ่งที่ยังไม่ได้ตรวจกับ Revit จริง (ผู้ใช้ช่วยดูเมื่อรัน)
1. API: `Stairs.GetStairsRuns/GetStairsLandings`, `StairsRun.GetStairsPath/GetFootprintBoundary/ActualTreadDepth/...` ใช้ได้ใน 2026 และ Run/Landing/Stairs เป็น host ของ Rebar ได้จริง
2. ทิศ `GetStairsPath` เริ่มจากล่างขึ้นบน และ `BaseElevation` ของ Run/Landing วัดจาก Base Level ของ Stairs
3. `BaseElevation` ของ Landing เป็นผิวบน (โค้ดตรวจเทียบปลายบนของช่วงและเตือนใน log ถ้าไม่ตรง)
4. การเรียงซ้ำ (`SetLayoutAsFixedNumber`) ไปทางทิศ normal เดียวกับที่ส่งให้ตอนสร้าง (เหมือนปลอกคาน) ถ้าทิศกลับ เหล็กจะเรียงออกนอกบันได
5. ชื่อพารามิเตอร์ "Structural Depth" ใน Run Type (ถ้าอ่านไม่ได้ฟอร์มใช้ 0.15 ม. — ผู้ใช้แก้เองได้)
6. สีใน 3D view (`OverrideGraphicSettings`) แสดงจริงกับ Rebar

## ค่า/คำถามที่ต้องให้วิศวกรหรือผู้ใช้ยืนยัน
**ชื่อกลุ่ม** (คลิปอ่านไม่ชัด — ตั้งตามหน้าที่ทางวิศวกรรม):
1. "เหล็กหลักท้องบันได" = เหล็กหลักล่าง ขนานความลาด ใช่หรือไม่
2. "เหล็กต่อ/ยืดที่ชานและคาน" = เหล็กบน (รับโมเมนต์ลบ) ที่ปลายต่อชาน/คาน ตัว L ยื่นเข้าชาน 0.40 ม. ลงมาตามท้องช่วง 0.60 ม. ใช่ตามคลิปหรือไม่ (ค่าความยาว = ค่าสมมติ; ปลายล่างปิดไว้เป็นค่าตั้งต้น เพราะความลึกของคานรองรับล่างไม่ทราบ)
3. "เหล็กลูกนอน-ลูกตั้ง" = ตัว L ตามรอยขั้นหรือไม่ (หรือเป็นเหล็กตรงแยกลูกนอน/ลูกตั้ง?) — ตอนนี้ 1 ชุดต่อขั้น เรียงตามความกว้างด้วยระยะที่กำหนด
4. "เหล็กกันร้าว/ตามขวาง" = เหล็กแนวขวาง วางบนเหล็กหลัก (ชั้นเดียวกับท้อง) หรือชั้นบนของแผ่นด้วย?
5. ในคลิปมีกี่กลุ่มจริง (3 หรือ 4) และกลุ่มไหนใช้ @0.15 กลุ่มไหน @0.2 (ค่าตั้งต้น: หลัก 0.15 ที่เหลือ 0.2)

**ค่าทางวิศวกรรม**: ระยะหุ้ม 25 มม., ความหนาท้องบันได/ชานตั้งต้น 150 มม. และถือว่าวัดตั้งฉากความลาด, หางเหล็กหลักยื่น 300 มม., ตัวเลือกชั้นเหล็กซ้อน (หลักอยู่ล่างสุด → กันร้าว → ลูกนอน-ลูกตั้ง), ตะแกรงชานใช้ขนาด/ระยะชุดเดียวกับ "หลัก"/"กันร้าว", ไม่มีเหล็กบนของชาน, ไม่มีงอปลาย/ตะขอ (ใช้เหล็กเส้นตรงตามรูปทรงเท่านั้น), ไม่ได้เช็คระยะทาบ
