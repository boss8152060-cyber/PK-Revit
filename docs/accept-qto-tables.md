# เกณฑ์ตรวจรับ: QTO Tables (0.1.0 — ยังไม่เคยรันใน Revit)

ปุ่ม `QtoTables.pushbutton` ในแท็บ PK Revit (กลุ่ม Roof Master) — สรุปปริมาณโครงหลังคาและวัสดุมุง
ตรวจแล้วเฉพาะ syntax (python ast) และ unit test ของ `qto_calc.py` (`python test_qto_calc.py`) **ไม่ได้ทดสอบใน Revit**

## เตรียม
- โปรเจกต์ Revit 2026 ที่สร้างโครงด้วยปุ่ม Rafter/Purlin/Hip Ridge/Valley (Structural Framing ที่ชื่อ type มีคำ แป / จันทัน / ตะเฆ่(ตะเข้)สัน / อกไก่ / รางน้ำ / ตะเฆ่(ตะเข้)ราง / ดั้ง)
- (ถ้าต้องการน้ำหนัก) เพิ่มพารามิเตอร์ type ชื่อ `น้ำหนักต่อเมตร` หรือ `Weight per meter` (ชนิด Number หรือ Mass per Unit Length) ใส่ค่า กก./ม.
- (ถ้าต้องการวัสดุมุง) สร้างด้วยปุ่ม Roof Cover โดยเลือก type/material ของแผ่น ครอบ ปั้นลม เชิงชาย
- ติดตั้ง `PKRevit.extension` ใหม่ (มี `lib/`) แล้ว pyRevit > Reload

## วิธีนับ/ข้อจำกัดที่ต้องรู้
- **โครง**: จัดชนิดจากชื่อ type เท่านั้น (ตรวจตามลำดับ อกไก่ → ตะเฆ่ราง → รางน้ำ → ตะเฆ่สัน → จันทัน → ดั้ง → แป) type ชื่อไม่ตรงจะไม่ถูกนับ แต่แสดงในหมายเหตุ/CSV
- ความยาว = Cut Length ของ Structural Framing (สำรอง: ความยาวเส้น Location) ไม่รวมการเผื่อ/ต่อทาบ
- **น้ำหนัก**: ไม่มีค่าตั้งต้น ถ้า type ไม่มีพารามิเตอร์ จะเว้นว่างและไม่เดา การแปลงหน่วยของพารามิเตอร์ชนิด Mass per Unit Length ใช้ `UnitTypeId.KilogramsPerMeter` — **ต้องตรวจจริงว่าค่าตรง**
- **วัสดุมุง**: Roof Cover (DirectShape) ไม่ได้เก็บชนิดชิ้นงานไว้ จึงแยกชนิดจาก **ชื่อ material** ที่ทาสีไว้ (คำ ridge/ครอบ, verge/ปั้นลม, fascia/เชิงชาย, ที่เหลือที่ชื่อบ่งแผ่น เช่น monier/metal/sheet) ชิ้นที่ไม่ได้ทาสีหรือชื่อไม่ตรงจะรวมเป็น "แยกชนิดไม่ได้"
- พื้นที่แผ่นมุง = ครึ่งหนึ่งของพื้นที่ผิวรวมของ solid (≈ ผิวบน เกินจริงเล็กน้อยจากด้านข้างแผ่น); ครอบ/ปั้นลม/เชิงชายแสดงพื้นที่ผิวรวม **ไม่ใช่ความยาว** (ยังไม่มีความยาวแนว)
- Schedule โครงหลังคาครอบคลุม Structural Framing **ทุกตัวในโปรเจกต์** (ไม่กรองตามชนิด); Schedule วัสดุมุงกรอง Comments ที่มี `PKRevit:roofcover:` แยกตามหลังคา (Comments) นับจำนวนชิ้น ไม่มีพื้นที่
- ขอบเขตเป็นทั้งโมเดลเสมอ (ยังไม่มีโหมดเฉพาะที่เลือก)

## ค่าที่รอยืนยัน
- ชื่อพารามิเตอร์น้ำหนักต่อเมตรที่ทีมใช้จริง (ปัจจุบันรองรับรายชื่อใน `qto_calc.WEIGHT_PARAM_NAMES`)
- รูปแบบตาราง/คอลัมน์ในคลิป "QTO Tables" (ไม่ได้ตรวจเทียบกับคลิป — เป็นการออกแบบตามโจทย์)
