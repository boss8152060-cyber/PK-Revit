# เกณฑ์ตรวจรับ: Rebar พื้น (0.1.0 — ยังไม่เคยรันใน Revit)

## เตรียม
- โปรเจกต์ Revit 2026 มีพื้น (Floor / Structural Floor) แนวราบ: สี่เหลี่ยม, ตัว L, คางหมู, และพื้นที่มีช่องเปิด (Opening หรือ sketch loop ด้านใน)
- มี Rebar Bar Type ชื่อ `RB6/RB9/DB10/...` ที่ใช้ (โหมดเหล็กเส้น)
- โหมดไวร์เมช: ต้องมี Fabric Sheet Type อย่างน้อย 1 แบบ (Structure > Reinforcement Settings / โหลด family) — ทดสอบทั้งกรณี "มี" และ "ไม่มี"
- ติดตั้ง `PKRevit.extension` ใหม่ (รวม `lib/`) แล้ว pyRevit > Reload

## กรณีขอบ / ข้อจำกัดที่รู้
- พื้นเอียง/ผิวบนไม่ราบ → ข้ามและบันทึกใน log (ยังไม่รองรับ)
- ชั้นเหล็กรวมหนาเกินความหนาพื้น → ไม่ใส่ พร้อมบันทึกใน log
- ส่วนโค้งของขอบพื้นถูกแปลงเป็นเส้นตรงสั้นๆ (Tessellate) ปลายเหล็กจึงเป็นค่าประมาณ
- ที่มุมเว้า (reflex) การหดด้วยระยะหุ้มคิดทีละขอบ อาจชิดกว่าระยะหุ้มเล็กน้อยที่จุดมุม
- เหล็กเส้นสร้างทีละเส้น ไม่ใช้ layout set (รองรับรูปทรงอิสระ) พื้นใหญ่ + @0.15 จะมีจำนวน Rebar เยอะและช้า
- ไวร์เมชยังไม่เจาะช่องเปิด/ไม่จัดทิศตามผืน; บน-ล่างและระยะหุ้มของไวร์เมชขึ้นกับค่า cover ของพื้นใน Revit ไม่ได้ใช้ช่อง "ระยะหุ้ม" ในฟอร์ม
- ไม่ตัดท่อนตามความยาวสต็อก ไม่ใส่ระยะทาบ (เป็นเรื่องของ BBS ในอนาคต)

## ที่ยังไม่ได้ทดสอบ/เสี่ยงที่สุด
- **API ไวร์เมช** (`FabricArea.Create` / `FabricSheet.Create`) เขียนจากความจำ signature อาจไม่ตรงกับ Revit 2026 — สคริปต์ลองสองวิธีตามลำดับและบันทึกข้อความผิดพลาดลง log ถ้าล้ม ให้ส่ง log กลับมาเพื่อแก้
- การอ่านผิวบน/ล่างและ `GetEdgesAsCurveLoops` ของพื้นที่มี Opening ยังไม่เคยรันจริง

## ค่าที่รอยืนยันจากวิศวกร
- ระยะหุ้ม 0.02 ม. (ตามคลิป) เหมาะกับพื้นภายในเท่านั้นหรือไม่
- ลำดับชั้น: ทิศ X อยู่ริมนอกสุด (ล่างสุด/บนสุด) ทั้งบนและล่าง — ตีความเอง
- ระยะเริ่มเหล็กแถวแรก = หุ้ม + d/2 จากขอบ, ช่องท้ายเหลือ ≥ 0.25×ระยะ จึงเติมเส้นท้าย (ระยะห่างจริง ≤ ที่กรอก)
- ความยาวงอลงของเหล็กเสริมริม = 12d (ตามคลิป "12db" ของโมดูลอื่น) และความยาวเข้าพื้นตั้งต้น 0.80 ม. — ค่าสมมติทั้งคู่

## คำถามเปิด (ความหมายในคลิปยังไม่ชัด)
1. "เหล็กหนวดกุ้ง 42 ท่อน" คืออะไรกันแน่: (ก) เหล็กบนเสริมที่ริม/เหนือคาน (ข) เหล็กยกสลับงอขึ้น-ลง (ค) เหล็กเสริมมุม ฯลฯ — ตอนนี้ทำเป็น (ก) แบบง่าย ปิดไว้ตั้งต้น
2. "เหล็กเสริมริม" กับ "หนวดกุ้ง" เป็นตัวเลือกเดียวกันหรือสองตัว
3. ในคลิปไวร์เมช "1 ผืน" = หนึ่งแผ่นต่อพื้นหนึ่งผืน หรือแบ่งตามขนาดแผ่นมาตรฐาน
4. ทิศ X/Y ในคลิปอิงแกนโมเดล หรือแกนตามด้านยาวของพื้น
5. พรีวิว 3D (สีส้ม/เขียวตามชั้นเหล็ก) ในคลิปยังไม่ได้ทำในโมดูลนี้ — ต้องการหรือไม่
