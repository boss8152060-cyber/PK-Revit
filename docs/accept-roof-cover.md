# เกณฑ์ตรวจรับ: Roof Cover (0.4.0 — ยังไม่เคยรันใน Revit)

ที่มาฟีเจอร์: features.md หมวด C (4 ขั้นติ๊กเลือกได้; ครอบข้าง "ยังพัฒนาอยู่" ตามคำบรรยายในคลิป)

## สถานะแต่ละขั้น
| ขั้น | สถานะ |
|---|---|
| 1 แผ่นหลังคา | ทำแล้ว (ตัวแข็งหนาเต็มผืน ยังไม่ตัดแต่งชายคา/ซ้อนทับ/ลอนกระเบื้อง) |
| 2 ครอบสัน + ตะเฆ่สัน | ทำแล้ว (หน้าตัดจั่วสามเหลี่ยมง่าย ๆ ยังไม่ miter ปลายที่ยอดรวม) |
| 3 ครอบข้าง (ปั้นลม) | **ทดลอง/ยังพัฒนาอยู่** ปิดเป็นค่าตั้งต้น ติ๊กเปิดเอง (ตามที่ผู้พูดในคลิปบอก) |
| 4 เชิงชาย | ทำแล้ว (แผ่นตั้งห้อยจากขอบชายคา) |

## วิธีทำงาน (ตัดสินใจเอง — โปรดยืนยัน)
- ชิ้นงานเป็น DirectShape ในหมวด Generic Models ไม่ใช่ family จริง จึงนับเป็นปริมาณ/Schedule ตามหมวด Generic Models; material ทาสีผิวจาก material ของ type ที่เลือก
- ขอบจำแนกอัตโนมัติ: แนวพับนูน=สัน/ตะเฆ่สัน, ขอบราบ+ผืนยกเข้าด้านใน=ชายคา, ขอบลาดไม่มีผืนชน=ขอบข้าง; รองรับเฉพาะขอบเส้นตรง

## เตรียม
- โปรเจกต์ Revit 2026 มี Roof (แบบจั่ว/ปั้นหยา) ที่มีผืนลาดตั้งแต่ 2 ผืน
- มี type ในโปรเจกต์ที่ชื่อเช่น Monier, Prestige, Oriental, Metal Sheet, Fascia (Roof/Fascia/Curtain Panel/Generic Model)
- ติดตั้ง `PKRevit.extension` ใหม่ (รวม `lib/revotech/roofgeo.py`) แล้ว pyRevit > Reload

## กรณีขอบ
- ขอบโค้ง/ดิ่ง: ข้ามและบันทึกใน log
- แนวรางเว้า: ข้ามไม่ครอบ (บันทึกใน log)
- ผืนหลังคาที่ถูกจอยกับแป/จันทัน แตกเป็นชิ้นย่อยระนาบเดียวกัน: ถือเป็นรอยต่อ ไม่ทำเชิงชายซ้ำ
- หลังคาชั้นเดียว (shed) ขอบบนราบ: ข้าม ไม่ทำเชิงชาย
- ถ้าสร้างล้ม: ย้อนกลับทั้งหมด

## สิ่งที่ยังไม่ได้ทำ / ข้อจำกัด
- ไม่ใช่ family กระเบื้องลอน/ครอบสำเร็จรูปจริง (ยังไม่รู้ family ที่ใช้)
- ยังไม่ตัดมุมครอบที่ยอดตะเฆ่ชนกัน, ไม่ตัดแผ่นมุงตามชายคา/ช่องเปิด
- ขนาดครอบ (กว้าง 300 / สูง 80), เชิงชาย (สูง 200 / หนา 30), แผ่นมุงหนา 20 เมื่อ type ไม่ระบุ เป็นค่าสมมติ

## คำถามที่ต้องถามผู้ใช้
1. วัสดุ/family ที่ใช้จริงคืออะไร (SCG CPAC Monier, Prestige, Oriental, Metal Sheet, Fascia เป็น Roof type, Curtain, หรือ family โหลดเอง)? ถ้าเป็น family ลอนกระเบื้อง ต้องการให้วางทีละแผ่น (array) หรือเป็นผิวเรียบแทน?
2. ขนาดมาตรฐาน: ความกว้าง/สูงครอบสัน, หน้าตัดเชิงชาย/ปั้นลม, ระยะยื่นชายคา
3. ครอบข้าง (ปั้นลม) ในคลิปหน้าตาเป็นอย่างไร และต้องการให้ทำจริงจังหรือคงเป็นตัวเลือกทดลอง
4. ต้องการให้ชิ้นงานอยู่หมวดอะไร (Generic Models ตอนนี้ / Roofs / Fascia) เพื่อทำ QTO
5. ขอไฟล์โปรเจกต์ตัวอย่างที่มีหลังคาและ type เหล่านี้ เพื่อใช้ทดสอบ
