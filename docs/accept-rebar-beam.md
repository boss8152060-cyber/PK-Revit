# เกณฑ์ตรวจรับ: Rebar คาน (0.3.x — ยังไม่เคยรันใน Revit)

ไฟล์: `REVOTECH.panel/RebarBeam.pushbutton/` + `lib/revotech/beamcalc.py` (คำนวณล้วน ทดสอบนอก Revit: `python test_beamcalc.py` ผ่าน 8 เคส)
**สถานะ: ตรวจเฉพาะ syntax (ast) และ unit test ของ beamcalc — ส่วนที่เรียก Revit API ยังไม่เคยทดสอบ**

## เตรียม
- โปรเจกต์ Revit 2026 มีคานคอนกรีต (Structural Framing, Structural Type = Beam) แนวตรง หน้าตัดสี่เหลี่ยม ทั้งแนวนอนและลาด
- มี Rebar Bar Type `DB10…DB32`, `RB6/RB9` ที่ใช้; ติดตั้ง extension ใหม่ (ต้องมี `lib/`) แล้ว pyRevit > Reload
- เตรียมคาน 3 แบบ: ช่วงสั้น (~6 ม.), ช่วงยาว ~12 ม., ช่วงยาว ~25 ม.

## กรณีขอบ (ต้องข้าม/เตือน ไม่ crash)
- เหล็กเกินความกว้างคาน, ชั้นบนชนชั้นล่าง (คานตื้น), หน้าตัดเล็กกว่าระยะหุ้ม → ข้ามคานนั้น พร้อมเหตุผลใน log/popup
- ขางอ 12d ยาวกว่าความลึกคาน → เตือนใน log
- คานโค้ง/ไม่ใช่เส้นตรง/ตั้งดิ่ง → ข้าม (ยังไม่รองรับ)
- Bar Type ที่เลือกไม่มี → ฟอร์มไม่ยอมสร้าง

## จุดเสี่ยงที่ต้องดูตอนทดสอบจริง (ยังไม่ได้ยืนยันกับ Revit)
1. **ทิศงอ 90° (Left/Right)**: คำนวณ normal ให้ขางอชี้ลง (บน) / ขึ้น (ล่าง) ตามสมมติฐาน "Left = n×d" ถ้ากลับด้านต้องกลับสัญญาณ normal ใน `script.py`
2. `RebarHookType.Multiplier` ใช้เทียบหา Hook เดิม; ถ้า property ชื่อต่างจะสร้าง Hook ใหม่ซ้ำ (ไม่ผิดแต่รก)
3. เหล็กวางที่ปลายเรขาคณิตของคาน ลบระยะหุ้ม — ถ้าคานถูก join กับเสา ขอบเขตจะอยู่ที่หน้าเสา (ไม่ฝังเข้าเสา)
4. ระยะ Maximum Spacing ของปลอก: จำนวนจริงจาก Revit อาจต่างจาก "~N ตัว" ใน popup ±1 ต่อโซน
5. เหล็กข้างใช้จุดต่อเดียวกับเหล็กบน; ชั้น 2 ใช้จุดต่อเดียวกับชั้น 1 ของด้านนั้น (ยังไม่เหลื่อม)

## ค่าที่รอวิศวกรยืนยัน (ตั้งต้นทั้งหมดเป็นค่าสมมติ)
- ขางอ 90° = 12d (ตามคลิป/มยผ. 1103-64) และเป็นการงอที่ปลายคานทั้งสองข้าง
- ตะขอปลอก 135° = 6d (ขั้นต่ำ 75 มม. ยังไม่ได้ใส่ใน Hook type)
- ระยะทาบ 40d (เหล็กบนและล่างเท่ากัน) — ตามขนาดใหญ่สุดของด้านนั้น
- ความยาวเหล็กสูงสุดต่อท่อน 10 ม.
- ตำแหน่งต่อ: บนต่อกลางช่วง (i·L/n), ล่างเลื่อนเข้าหาปลาย L/(2n) — ตามที่เห็นในคลิป "บนต่อกลาง/ล่างต่อที่เสา" แต่คานเดี่ยวไม่มีเสากลางช่วง จึงใช้ L/(2n) แทน
- ระยะใสระหว่างเหล็กขั้นต่ำ max(25 มม., d)
- ระยะปลอกตั้งต้น 0.10 (ปลาย) / 0.20 (กลาง), โซนปลาย 0.80 ม. (ควรเป็น 2h หรือตามผู้ออกแบบ), ระยะหุ้ม 25 มม.
- ตำแหน่งเหล็กเสริมพิเศษ: เสริมบน "ปลายทั้งสองข้างยาว L/n", เสริมล่าง "กลางช่วงเว้นปลายละ L/n" (n = 3–6) และวางเป็นชั้นถัดไป ไม่แทรกในชั้นเดียวกับเหล็กหลัก
- ไม่มีการเผื่อฝังเหล็กเข้าเสา/ความยาวยึดเหนี่ยว (anchorage) นอกจากขางอ
