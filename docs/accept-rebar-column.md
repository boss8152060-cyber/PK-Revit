# เกณฑ์ตรวจรับ: Rebar เสา (0.3.0 — ยังไม่เคยรันใน Revit)

## เตรียม
- โปรเจกต์ Revit 2026 มีเสาคอนกรีต (Structural Columns) หน้าตัดสี่เหลี่ยม แกนตั้ง
- มี Rebar Bar Type ชื่อ `DB12/DB16/...` และ `RB6/RB9` อย่างน้อยที่ใช้ (Structure > Reinforcement Settings / โหลดจาก template)
- ติดตั้ง `PKRevit.extension` ใหม่ (โฟลเดอร์ `lib/` ต้องมาด้วย) แล้ว pyRevit > Reload

## ขั้นทดสอบและผลที่คาดหวัง
| # | ทำ | คาดหวัง |
|---|---|---|
| 1 | ไม่เลือกอะไร กดปุ่ม Rebar เสา | ขึ้น "กรุณาเลือกเสาก่อน" แล้วจบ |
| 2 | เลือกเสา 1 ต้น กดปุ่ม | ฟอร์มธีมขาว-ดำ (PK)เปิด แสดง "เสาที่เลือก: 1 ต้น" และด่านตรวจ ✓/✗ ตาม bar type |
| 3 | เลือก 4 เส้น DB16, ปลอก RB9 @0.15/0.10 โซน 0.60 หุ้ม 0.025 แล้วสร้าง | เหล็กยืน 4 เส้นที่มุม, ปลอกเป็น 3 โซน (ปลายถี่-กลาง-ปลายถี่), popup สรุป, ไฟล์ log ใน `%LOCALAPPDATA%\PKRevit\Rebar_column.txt` |
| 4 | Ctrl+Z ครั้งเดียว | เหล็กหายหมดทั้งชุด |
| 5 | สร้างซ้ำสองครั้งโดยติ๊ก "แทนที่" | ไม่ซ้อนทับ (ชุดเดิมถูกลบ) |
| 6 | ติ๊ก "ทั้งอาคาร" | ใส่เสาทุกต้นที่ type เดียวกัน |
| 7 | 8, 12, 16 เส้น กับเสา 0.3x0.6 | เหล็กเรียงสมมาตร ด้านยาวได้มากกว่า |

## กรณีขอบ
- เสาที่หน้าตัดเล็กเกินระยะหุ้ม/ขนาดเหล็ก → ข้าม พร้อมบันทึกใน log
- ไม่มี Bar Type ที่เลือก → ฟอร์มไม่ยอมสร้าง บอกชื่อที่ขาด
- เสาไม่ใช่สี่เหลี่ยม/เอียง: **ยังไม่รองรับ** (ผลอาจผิด)

## ค่าที่รอยืนยันจากวิศวกร
ปลายตะขอปลอก 135° = 6d (ขั้นต่ำ 75 มม. ยังไม่ได้ใส่ใน Hook type), ระยะทาบ 40d, ค่าระยะปลอกและความยาวโซนปลายตั้งต้น
